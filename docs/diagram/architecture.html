Agentic CLI Architecture

Provider-agnostic agentic coding tool with tool registry, context management, and completion review

Core Agent Loop
Central orchestration layer managing the agent lifecycle, step execution, and loop guards
⟳ AgentLoop (agent.py)
Main agent execution loop with max steps, loop detection (A-B-A-B cycles), output token limit handling, and continuation callbacks
agent.py AgentState ContextManager
📝 CompletionResolver (completion.py)
Optional completion review using a separate model to verify task completion, with retry logic and findings tracking
completion.py max_attempts review_provider
🔄 ContextManager (context.py)
Context window estimation, compaction (eliding old tool outputs, dropping oldest turns), token calibration from provider usage
context.py compact() calibrate()
Provider Adapters
OpenAI-compatible HTTP client with streaming, retries, and multi-provider support
🌐 OpenAICompatibleProvider (provider.py)
Async HTTP client for any OpenAI-compatible API (NVIDIA NIM, Ollama, OpenAI, Anthropic, OpenRouter) with exponential backoff, Retry-After support, and streaming
provider.py httpx.AsyncClient stream=True

Request Flow

1
User Input
User types task in REPL or uses slash command
2
Normalize & Plan
CLI normalizes input, creates todos, builds system prompt with tools/skills/agents
3
Agent Loop
AgentLoop.run(): compact context → provider.complete() → execute tools → repeat
4
Tool Execution
PermissionGate checks safety → callback for user approval → registry.execute()
5
Completion Review
CompletionResolver uses review_provider to verify task completion, retries if needed
6
Response & Session
Display result, save session transcript to JSONL
