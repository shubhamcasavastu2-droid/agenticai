Sequence Diagrams - AI Agent CLI Architecture

Overview

Sequence diagrams for key flows in the AI Agent CLI codebase.

  • Main Agent Loop Flow - Complete user interaction from startup to completion review
  • Tool Execution Flow - Detailed tool execution with permission checks, path validation
  • Completion Review Flow - How the reviewer verifies task completion
  • Input Normalization Flow - How user input is normalized before main agent
